1 · Get the agent

JARVIS controls your PC through a small helper program running on your laptop. Download it, unzip, and double-click start_jarvis_agent.bat. It opens this page already connected.

2 · Not connected? Paste the token

The token stays in this browser and on your laptop. Never put it on GitHub.

3 · The AI brain (Ollama)

Jarvis thinks locally with Ollama: no cloud AI, no API key, no cost. Everyday commands run instantly without the model.

Better model: ollama pull llama3.2:3b, then put {"model":"llama3.2:3b"} in ~/.jarvis/config.json and restart the agent.

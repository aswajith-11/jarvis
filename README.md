# Jarvis Personal AI

A sci-fi voice assistant that runs entirely in the browser. No server or API keys needed.

## Publish on GitHub Pages
1. Create a new repository on github.com, e.g. `jarvis`.
2. Upload `index.html` and `README.md` (Add file > Upload files > Commit).
3. Open Settings > Pages. Under "Branch", pick `main` and `/ (root)`, then Save.
4. After about a minute your site is live at `https://<your-username>.github.io/jarvis/`.

Use the https link. Browsers only allow the microphone on https.

## Use it
- Press the glowing core, the mic button, or the Space bar, then speak. Chrome or Edge work best.
- Or type in the box at the bottom.
- Try: "hello", "what time is it", "battery", "system info", "open youtube", "search black holes",
  "play lofi music", "start work mode", "quote", "change background", "code red", "stand down".
- Profile stores your name locally. Automations lets you add or edit modes with your own website links.

## Limits
A web page can't launch desktop apps or control the PC. Modes open websites instead.
